# CarCar

Компактный портативный AI-чат для Windows 10/11 x64. Rust + Tauri 2, React + TypeScript, Markdown и CodeMirror 6. Без backend, регистрации, телеметрии и истории переписки.

## Запуск готовой сборки

Распакуйте архив и запустите `carcar.cmd`. Из CMD в папке приложения достаточно:

```cmd
carcar
```

Загрузчик копирует EXE в `%TEMP%\CarCar\runs\<UUID>`, запускает его, ждёт закрытия и удаляет временную копию. CMD остаётся открытым до завершения, чтобы загрузчик мог выполнить очистку. Также можно запустить `CarCar.exe` напрямую: его временный профиль очищает короткоживущий вспомогательный процесс этого же EXE.

`carcar` работает из любой папки, только если папка с `carcar.cmd` и `carcar-launcher.exe` уже добавлена пользователем в PATH. Приложение не меняет PATH и автозагрузку.

## Первый запуск из CMD через GitHub Releases

Публичные релизы: https://github.com/aladiiplyton-alt/CarCar/releases

Одна и та же команда для CMD на другом Windows-компьютере, без заранее скачанного архива и без путей к папкам владельца проекта:

```cmd
curl -fL --retry 3 https://aladiiplyton-alt.github.io/CarCar/c3 -o "%TEMP%\cc.cmd" && "%TEMP%\cc.cmd"
```

Короткая ссылка ведёт на статический CMD-загрузчик этого проекта на GitHub Pages. Команда скачивает его во временную папку и сразу выполняет. Он проверяет закреплённый SHA256 сценария запуска, затем скачивает и проверяет EXE из GitHub Releases. После закрытия удаляются временные загрузки, включая временный `cc.cmd`. Если сохранить `start.cmd` в своей папке, он остаётся для повторного запуска. Папка запуска и имя пользователя Windows значения не имеют. Нужны Windows 10/11 x64, доступ к GitHub и установленный WebView2; при отсутствии Runtime загрузчик предложит открыть официальный сайт. [curl входит в современные версии Windows](https://learn.microsoft.com/en-us/windows/curl/).

Начальный curl повторяет поддерживаемые временные ошибки до трёх раз сверх первого запроса. Загрузка стартового сценария, метаданных и файлов релиза делает до трёх попыток. Повреждённый EXE удаляется и скачивается повторно. Если GitHub API недоступен, используется опубликованный релиз v1.0.0. Все попытки ограничены: при недоступном сервере, блокировке сети или запрете запуска со стороны Windows выводится ошибка. Работающий Wi-Fi сам по себе не гарантирует доступность сервера; 100% успешного скачивания обещать нельзя.

Предыдущая команда с `raw.githubusercontent.com/.../main/start.cmd` тоже поддерживается; временное имя `carcar-start.cmd` очищается так же. Файлы `docs/c`, `docs/c2` и `docs/c3` синхронизируются со `start.cmd` командой `./scripts/sync-launcher.ps1`. CMD-файлы публикуются в ASCII с окончаниями CRLF и не меняют кодовую страницу консоли. `.gitattributes` сохраняет их байты в Git, чтобы GitHub Pages не заменял CRLF на LF. Адрес `c3` открывает личный профиль; `c2` также обновляется. Новый адрес позволяет получить актуальный файл, даже если старый адрес `c` остался в кэше. Настоящий ключ на GitHub Pages не публикуется.

Встроенной команды `carcar` на совершенно новом компьютере нет. Без подготовки загрузчика используется строка выше. Приложение не меняет PATH автоматически и не запрашивает обход политик безопасности компьютера.

Вариант напрямую через PowerShell из CMD, без curl:

```cmd
powershell -NoProfile -Command "$ErrorActionPreference='Stop'; $r='aladiiplyton-alt/CarCar'; [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; for($i=0;$i -lt 3;$i++){try{$b=(Invoke-WebRequest -UseBasicParsing -TimeoutSec 40 ('https://github.com/'+$r+'/releases/download/v1.0.0/bootstrap-profile-c8dbc631e019d86e.ps1?carcar='+[guid]::NewGuid())).Content; if($b -is [string]){$b=[Text.Encoding]::UTF8.GetBytes($b)}; $h=[BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($b)).Replace('-',''); if($h -ne 'c8dbc631e019d86edc1e2d4b18a1e521f922ef210862eb4f87c3a4cd0038551c'){throw 'Bootstrap SHA256 mismatch'}; break}catch{if($i -eq 2){throw}; Write-Host 'CarCar: retrying the startup download...'; Start-Sleep -Seconds 2}}; & ([scriptblock]::Create([Text.Encoding]::UTF8.GetString($b))) -Repository $r"
```

Команда загружает сценарий запуска из указанного релиза. Он скачивает загрузчик, приложение и SHA256SUMS, проверяет хеши и выполняет запуск из временной папки. После закрытия удаляет загрузки. Это не устанавливает постоянную команду `carcar`. Если нужен постоянный загрузчик, сохраните `carcar.cmd` и `carcar-launcher.exe` в выбранной папке; `repository.txt` со строкой `aladiiplyton-alt/CarCar` позволяет загрузчику скачивать EXE при отсутствии локальной копии.

При запуске этой команды введите пароль личного профиля в CMD. API Key, API Base URL и модель владельца подставятся автоматически. Пароль вводится один раз при каждом запуске и не отправляется на сервер. Он предоставляется владельцу отдельно, не находится в Git, в публичном EXE или на GitHub Pages. Сам EXE остаётся универсальным: при прямом запуске без профиля API можно настроить вручную.

В GitHub Releases размещён только зашифрованный профиль. Его расшифровка и проверка выполняются на компьютере пользователя: PBKDF2-HMAC-SHA256 (300 000 итераций), отдельные ключи AES-256-CBC и HMAC-SHA256, проверка MAC до расшифровки. Нужна .NET Framework 4.7.2+ для Windows PowerShell. Открытый ключ не записывается во временный файл: настройки передаются дочернему процессу через его окружение и остаются в памяти сеанса. После завершения прежние переменные процесса загрузчика восстанавливаются.

Ключ в поле настроек замаскирован. Человек, знающий пароль и получивший доступ к запущенному приложению, может показать ключ кнопкой в настройках или извлечь его из своего процесса. Пароль даёт доступ к использованию API владельца; он не скрывает ключ от того, кто разблокировал профиль. В личном локальном архиве по прежней просьбе владельца также сохранён приватный `carcar.local.env`; этот архив не публикуется.

Чтобы создать свой профиль, запустите `scripts/create-profile.ps1 -ConfigPath <private.env> -OutputDirectory <private-output>`, затем `scripts/sync-launcher.ps1`. Пароль будет записан только в личный `CarCar-Profile-Password.txt`, публичный `profile.public.json` содержит лишь имя зашифрованного файла и его SHA256. Загрузите зашифрованный `.carcar` и сформированный `bootstrap-profile-<hash>.ps1` в релиз, прежде чем публиковать обновлённый CMD. Старые версии bootstrap сохраняются, чтобы не ломать уже скачанные команды.

## API и приватная конфигурация

Нажмите шестерёнку: API Base URL (обычно с `/v1`), API Key, точное имя модели, максимум токенов, необязательная температура и потоковый режим. Изменения применяются к следующему запросу и не записываются на диск. Если провайдер не поддерживает streaming, снимите флажок. Температура по умолчанию не отправляется.

По просьбе владельца проекта добавлена автозагрузка ключа из `carcar.local.env`. Этот файл хранит ключ **на диске в открытом виде** и исключён из Git. Он является явным исключением из исходного требования хранить ключ только в памяти. Открытый ключ не вшивается в EXE и не публикуется в GitHub Releases; там доступен только зашифрованный профиль.

Для своего провайдера скопируйте `carcar.example.env` в `carcar.local.env` рядом с EXE либо рядом с загрузчиком и заполните его. Альтернатива — переменные `CARCAR_API_KEY`, `CARCAR_BASE_URL`, `CARCAR_MODEL`. `CARCAR_CONFIG` задаёт полный путь к приватному файлу. Приоритет: соседний файл EXE → `CARCAR_CONFIG` → отдельные переменные окружения → изменения в текущем окне настроек. При запуске из загрузчика он передаёт путь к своему файлу через `CARCAR_CONFIG`, не копируя ключ во временную папку.

Для режима «ключ только в памяти» удалите приватный файл, не задавайте ключ в переменных окружения и вводите его в настройках при каждом запуске. Сообщения отправляются прямо выбранному провайдеру; его правила хранения применяются отдельно.

## Диалог

- Enter — отправить, Shift+Enter — новая строка.
- Кнопка отправки во время запроса становится кнопкой остановки.
- Markdown: заголовки, списки, таблицы, цитаты, код.
- CodeMirror 6: Python, JavaScript, TypeScript, Rust, C++, Java, HTML, CSS, SQL; алиасы `py`, `js`, `ts`, `rs`, `c++`, а также JSX/TSX.
- Отдельное копирование кода и всего ответа через буфер обмена Windows.
- Очистка удаляет текущий диалог из интерфейса и прекращает запрос.
- HTML из ответа не исполняется. Удалённые изображения не загружаются; ссылки отображаются как текст с URL, чтобы AI-ответ не инициировал дополнительные сетевые запросы.

## Очистка и границы приватности

Диалог живёт в памяти React и запроса Rust. Нет localStorage, sessionStorage, IndexedDB, файлов истории, аналитики, служб, автозапуска, доступа к экрану, микрофону, камере, другим окнам или истории браузера. Пользователь видит статус «Запрос к API» во время обращения.

WebView2 запускается в incognito с отдельным профилем `%TEMP%\CarCar\profiles\<UUID>`. На диске возможны технические файлы WebView2, но приложение не записывает туда сообщения. При выходе отменяются запросы и уничтожается HTTP-клиент. Вспомогательный процесс ждёт завершения главного процесса и повторяет удаление профиля до 20 секунд. Загрузчик так же удаляет временный EXE; оставшиеся папки неработающих сеансов проверяются при следующем запуске. Сценарий первоначального скачивания использует `%TEMP%\CarCar-Bootstrap\<UUID>`.

Используемые временные папки проверяются на принадлежность CarCar; активные сеансы не очищаются. Если Windows или антивирус временно удерживают файл, очистка повторяется при следующем запуске. Приложение не обещает стирания следов из системных журналов, pagefile, дампов или памяти Windows. Содержимое, явно скопированное пользователем, остаётся в системном буфере обмена согласно настройкам Windows. Приватный `carcar.local.env` и исходный скачанный архив не удаляются: они нужны для повторного запуска.

## Требования

Windows 10 x64 / Windows 11 x64 и Microsoft Edge WebView2 Runtime. Python, Node.js и Rust конечному пользователю не нужны. Загрузчик проверяет стандартные папки Runtime и при отсутствии предлагает открыть официальный сайт: https://developer.microsoft.com/microsoft-edge/webview2/ . Runtime устанавливает сам пользователь. Подпись разработчика для EXE не настроена; Windows может показывать обычное предупреждение о неизвестном издателе.

## Сборка из исходников

Только разработчику нужны Node.js 22+, Rust stable MSVC, Microsoft C++ Build Tools с Windows SDK и WebView2. Инструменты, использованные для локальной сборки, не входят в приложение.

```powershell
npm ci
npm run build
cargo test --workspace --locked
./scripts/build.ps1
```

Результат — `release/CarCar.exe`, `release/carcar-launcher.exe`, `release/carcar.cmd`, `release/bootstrap.ps1`, `release/SHA256SUMS.txt`. Release-профиль: оптимизация размера, LTO, один codegen unit, strip и статический CRT. Исходники и frontend встроены в один EXE. Дополнительные языковые модули CodeMirror загружаются из встроенных ресурсов по мере необходимости.

Разработка:

```powershell
npm run tauri dev
```

Проверки интерфейса (с локальными тестовыми ответами, без настоящего ключа):

```powershell
npm run dev
# В другом терминале, с установленным Chrome:
npm run test:ui
```

Проверка настоящего провайдера запускается отдельно: задайте `CARCAR_CONFIG` и выполните `cargo test real_provider_smoke -- --ignored`. Она делает один небольшой платный запрос согласно тарифу провайдера. Обычные тесты не обращаются к нему.

## Публикация

Workflow `.github/workflows/release.yml` собирает Windows EXE при push тега `v*` и прикладывает публичные файлы без ключей. Перед публикацией проверьте изменения и создайте тег. Личный архив с `carcar.local.env` не публикуется. Для другого репозитория поменяйте адрес в README и `repository.txt`; загрузчику можно передать `CARCAR_REPOSITORY=owner/repository`.

Подробные результаты фактических проверок находятся в `TESTING.md`. Совместимость Windows 10 и чистая машина без WebView2 требуют отдельной проверки на соответствующих системах.
