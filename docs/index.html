CarCar

Вставьте строку в CMD на Windows 10/11 x64:

curl -fL --retry 3 https://aladiiplyton-alt.github.io/CarCar/c3 -o "%TEMP%\cc.cmd" && "%TEMP%\cc.cmd"

Введите пароль личного профиля в CMD. API Key, Base URL и модель подставятся автоматически. Ключ и пароль не публикуются открытым текстом. После разблокировки владелец компьютера с доступом к приложению может увидеть ключ в настройках.

Приложение скачивается во временную папку. При отсутствии WebView2 загрузчик предложит открыть официальный сайт установки.

Интернет и разрешение Windows на запуск необходимы. Абсолютная гарантия скачивания при недоступном сервере или блокировке сети невозможна.
